What I'm building

zsec — z/OS security, but with an API

A 64-bit native library that wraps RACF administration and System SSL, called through JNI and exposed as a Spring Boot REST API with RACF-backed logins. The goal: manage mainframe security from anywhere that can speak HTTP.

Certificate lifecycle, end to end

Discovering, tracking and renewing certificates across mainframe systems — native engines on z/OS, a central Kotlin backend, a React portal with live updates, and ACME integration for issuing. Lately thinking a lot about post-quantum crypto and what CNSA 2.0 means for all of it.

Password sync across worlds

A C++ Windows service that keeps passwords in step between Active Directory (across forests) and the mainframe. Lots of COM, ADSI and RACF permission puzzles.

Things I learned the hard way

  • char[61]One byte too short is enough to make an exception throw the wrong class name. Count your null terminators.
  • UnsatisfiedLinkErrorUsually not your code. Usually LIBPATH.
  • mkdir XXXXXXmktemp doesn't exist on USS, and the X's won't expand themselves.
  • EBCDIC ↔ ASCIIEvery encoding bug lives exactly on a boundary. Decide where the boundary is and guard it.
  • ftp asciiBinary files go over in binary. Every time. No exceptions.
